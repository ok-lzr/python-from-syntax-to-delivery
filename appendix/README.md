# appendix 附录目录

本目录存放附录 A–G 的配套代码与数据文件，正文见书稿附录。

| 附录 | 标题 | 本目录对应内容 |
|---|---|---|
| A | Python 3.12.9 安装与虚拟环境速查 | 无代码 |
| B | PEP 8 核心规则与代码检查工具 | 检查工具配置见根目录 `pyproject.toml`、`.pre-commit-config.yaml` |
| C | 常见异常与排查表 | 无代码 |
| D | `requirements.txt` 与依赖版本策略 | 版本清单见根目录 `requirements.txt`、`requirements-dev.txt` |
| E | 练习题参考答案与项目验收清单 | `appendix/exercises/`（随对应章交付） |
| F | 术语表 | 无代码 |
| G | 进一步学习路线 | 无代码 |

## 约定

- 附录中的可运行代码与章节示例同样遵循 PEP 8、行宽 ≤ 88，并纳入 CI。
- 附录文件命名 `附录字母_主题.py`，例如 `e_1_loop_answers.py`。
