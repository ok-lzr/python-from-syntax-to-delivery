- 示例文件按 `章_节_小节.py` 命名，一个文件只放一个小节的最小示例，例如 `5_1_1_def.py`。
- 综合实践代码放 `practice/`，每个实践一个子目录，含 `solution.py` 与 `test_solution.py`。
