## 目录约定

- 示例文件按 `章_节_小节.py` 命名，一个文件只放一个小节的最小示例，例如 `11_1_1_def.py`。
- 综合实践代码放 `practice/`，每个实践一个子目录，含 `solution.py` 与 `test_solution.py`。
- 预期报错的示例单独成文件，文件名以 `_error.py` 结尾，文件顶部注释标明「预期报错」。
